Remaining MVP implementation steps
These are the eight features still to implement. I've expanded the What it will do section to explain the actual functionality expected from each feature.
Step	Feature	What it will do
1	Cross-document verification	Compare information extracted from different documents belonging to the same loan application. Match the net salary from the payslip against salary credits in the bank statement. Compare employee name with bank account holder name. Check whether the employer name in the payslip is consistent with the salary transaction description. Identify mismatches, missing information and values that require manual verification. Generate structured findings with expected values, actual values, differences, explanations and supporting evidence.
2	Bank transaction classification	Analyze all extracted bank transactions and classify them into meaningful categories such as salary, other income, loan EMI, rent, utilities, groceries, shopping, cash withdrawals, transfers and other expenses. Identify recurring transactions, distinguish credits from debits, and detect potential EMI payments using transaction descriptions and patterns. Avoid treating transfers between the applicant's own accounts as income or expenses. Preserve the original transaction details and classification confidence.
3	Existing loan analysis	Extract information from existing loan statements, including original loan amount, outstanding principal, EMI amount, interest rate, loan tenure, repayment history and overdue amounts where available. Identify existing monthly debt obligations. Compare extracted loan details against EMI transactions found in the bank statement. Highlight missing or inconsistent loan information.
4	Financial calculation engine	Build a deterministic Python service that calculates financial metrics using extracted and verified information. Calculate average monthly income, average monthly expenses, existing monthly EMI obligations, total fixed obligations, disposable income, FOIR (Fixed Obligation to Income Ratio), debt-to-income ratio and estimated repayment capacity. Support calculations across multiple statement months where available. Keep all financial arithmetic in Python using Decimal, not LLM-generated calculations.
5	Additional document request workflow	Identify missing documents and information required to complete an investigation. Allow the AI to generate a specific document request with a reason. For example, when payslip salary does not match bank salary credits, request a salary revision letter or clarification. Allow the loan officer to view pending requests, upload additional documents, and resume the investigation after submission. Maintain request status, submitted documents and request history.
6	LangGraph underwriting orchestration	Build a stateful LangGraph workflow that coordinates the complete investigation. It should retrieve application documents, trigger extraction where necessary, run financial calculations, perform cross-document verification, identify missing information and route the application accordingly. Support conditional execution, retries, persistent state, checkpoints and human intervention. Avoid repeating completed extraction tasks when an investigation resumes.
7	Underwriting investigation report	Generate a consolidated report for each loan application. Include applicant and loan details, extracted financial information, verified monthly income, existing liabilities, financial calculations, document verification results, discrepancies, missing information and supporting evidence. Include risk indicators and suggested questions for the loan officer. Clearly distinguish verified facts from assumptions and unresolved findings. Provide a suggested outcome such as further review or additional information required, while leaving the final lending decision to a human reviewer. Save the report so it can be retrieved later.
8	End-to-end testing	Test the entire workflow using multiple synthetic applicants and financial document combinations. Include cases with matching salary information, salary discrepancies, multiple existing EMIs, missing documents, inconsistent bank balances, irregular income and extraction failures. Verify financial calculations, extraction caching, document requests, LangGraph state recovery and report accuracy. Check that failures are handled gracefully and that previously processed information is not unnecessarily extracted again.
